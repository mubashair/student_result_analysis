# student_result_analysis
A Student Result Analysis Project in NumPy uses 2D arrays to store and evaluate exam scores. Rows represent individual students, and columns represent distinct subjects. Built-in vector operations calculate total marks, subject averages, highest/lowest scores, and pass-fail ratios instantly without slow manual loops.Project Architecture & WorkflowData Setup: Store numerical marks in a multi-dimensional ndarray.Aggregation (Row/Column-wise): Use axis parameters (axis=0 for subjects, axis=1 for students) to sum or average.Statistical Evaluation: Find extreme values, mean, and standard deviation.Conditional Filtering: Apply Boolean masks to isolate passing or failing grades.
